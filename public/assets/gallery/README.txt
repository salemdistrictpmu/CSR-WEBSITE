# PHOTO GALLERY DIRECTORY (Salem District Administration Society)

Place your photo files here:
- img1.jpg (e.g. Smart Classrooms / Education)
- img2.jpg (e.g. Primary Healthcare Centre / Diagnostics)
- img3.jpg (e.g. Green Belt Afforestation / Tree Plantation)
- img4.jpg (e.g. Lake Restoration / Water Resources)
- img5.jpg (e.g. Women Skill Training / Livelihood)
- img6.jpg (e.g. Solar Street Lighting / Rural Infrastructure)
- img7.jpg (e.g. Mobile Medical Unit)
- img8.jpg (e.g. District Sports Arena)

Supported formats: .jpg, .jpeg, .png, .webp

To add more photos:
1. Copy your image into this folder (e.g., img9.jpg).
2. Open `src/components/HomeView.tsx` or `src/components/GalleryView.tsx`.
3. Add a new item into the `RECENT_INITIATIVES_GALLERY` array with `localPath: "assets/gallery/img9.jpg"`.
